# 🚔 Crime Record Management System

## 📌 Project Overview

The Crime Record Management System is a MySQL-based project designed to store and retrieve crime records, police station and officer details, victims, suspects, court cases, and evidence.

## 🎯 Project Objectives

- To store and manage crime-related information in a database.
- To retrieve crime details using SQL queries.
- To access related information about victims, suspects, officers, court cases, and evidence.
- To analyze crime records based on city and year.

## ✨ Key Features

- 📝 Store and retrieve crime records.
- 🚓 Manage police station and officer details.
- 🧑 Store victim and suspect information.
- ⚖️ Maintain crime type, case status, and court case details.
- 🧾 Store evidence details.
- 🔍 Filter crime records by city and year.
- 🔗 Retrieve related information using INNER JOIN.
- 📊 Count crimes by city using GROUP BY and COUNT.
- 🏛️ Filter court case verdicts using the LIKE operator.
- 📋 Sort query results using ORDER BY.

## 🛠️ Technologies Used

- 🗄️ MySQL
- 💻 SQL
